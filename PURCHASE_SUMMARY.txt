┌──────────────────────────────────────────────────────────────────────────────┐
│  🔄 FLUX COMPLET                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Acheteur clique "Acheter" sur TicketCard
     ↓
  2. PurchaseModal s'ouvre (Étape 1: Récapitulatif)
     ├─ Affichage événement, placement, prix
     ├─ Calcul frais plateforme (5%)
     ├─ Total affiché
     └─ Checkbox CGU (obligatoire)
     ↓
  3. Clic "Continuer vers le paiement"
     ↓
  4. POST /api/tickets/reserve
     ├─ Transaction atomique Prisma
     ├─ Billet → RESERVED
     ├─ Transaction → PENDING
     └─ Retour transactionId
     ↓
  5. Étape 2: Paiement
     ├─ Timer 15 minutes démarre
     ├─ Stripe CardElement affiché
     └─ Saisie carte
     ↓
  6. Clic "Payer"
     ↓
  7. POST /api/payments/create-intent
     ├─ Création Payment Intent
     ├─ Configuration séquestre (transfer_data, on_behalf_of)
     └─ Retour clientSecret
     ↓
  8. stripe.confirmCardPayment(clientSecret)
     ├─ Traitement Stripe
     └─ Retour paymentIntent.status = succeeded
     ↓
  9. Webhook payment_intent.succeeded
     ├─ Transaction → ESCROWED
     ├─ Ticket → SOLD
     ├─ Audit log créé
     └─ Emails envoyés (acheteur + vendeur)
     ↓
  10. Étape 3: Succès
      ├─ Animation succès
      ├─ Message confirmation
      └─ Redirection dashboard (3s)


┌──────────────────────────────────────────────────────────────────────────────┐
│  💰 CALCULS FINANCIERS                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  Exemple: Billet à 90€

  Prix billet:           90.00€
  Frais plateforme (5%): +4.50€
  ─────────────────────────────
  Total acheteur:        94.50€

  Répartition:
  • Acheteur paie:       94.50€
  • Vendeur reçoit:      90.00€
  • Plateforme garde:     4.50€

  Note: Stripe prélève ses propres frais (~1.4% + 0.25€) sur le montant plateforme
