│  🚀 DÉMARRAGE RAPIDE                                                         │

  1. Démarrer le serveur
     $ npm run dev

  2. Ouvrir dans le navigateur
     $ open http://localhost:3000/events

  3. Tester la recherche

  4. Tester les filtres
     → Cliquer sur un événement
     → Ajuster les sliders et checkboxes dans la sidebar
